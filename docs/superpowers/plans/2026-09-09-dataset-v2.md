# Dataset v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Παραγωγή αναπαραγώγιμου dataset v2 χωρίς normalized overlaps, με πλήρες manifest και προστασία των παλιών δεδομένων.

**Architecture:** Ένας κοινός κανόνας NFKC + whitespace collapse + casefold ορίζει την ταυτότητα review. Το preprocessing διατηρεί το καθαρισμένο αρχικό κείμενο, αφαιρεί όλες τις εγγραφές με αντικρουόμενα labels, προσθέτει σταθερό review_id και γράφει νέα immutable έκδοση. Οι experiment utilities επικυρώνουν ολόκληρη την πηγή πριν δημιουργήσουν artifacts.

**Tech Stack:** Python, pandas, pyarrow, YAML, SHA-256, pytest, Ruff.

**Execution:** Inline, με διαδοχικά red → green βήματα. Η εντολή του χρήστη εξουσιοδοτεί την υλοποίηση της ήδη τεκμηριωμένης σειράς. Δεν επαναλαμβάνεται συνέντευξη ή αίτημα έγκρισης πλάνου. Τα εξωτερικά GPU runs θα ακολουθήσουν αφού σταθεροποιηθούν τα δεδομένα.

## Task 1 — Κοινή ταυτότητα και deduplication

- [ ] Γράψε πρώτα public extraction test με `Great location` / `great  LOCATION`, καθώς και Unicode full-width παραλλαγή. Επιβεβαίωσε ότι αποτυγχάνει στο σημερινό preprocessing.
- [ ] Πρόσθεσε κοινό identity helper:

```python
import hashlib
import unicodedata

NORMALIZATION_VERSION = "nfkc-whitespace-casefold-v1"

def canonical_text(text: str) -> str:
    return " ".join(unicodedata.normalize("NFKC", text).split()).casefold()

def review_id(text: str) -> str:
    return hashlib.sha256(canonical_text(text).encode("utf-8")).hexdigest()
```

- [ ] Χρησιμοποίησε canonical keys μετά το υπάρχον clean/truncate. Διατήρησε το original cleaned text για modeling/display. Απόφυγε score thresholds.
- [ ] Πρόσθεσε νέο failing test όπου το ίδιο canonical text εμφανίζεται με positive και negative label. Αφαίρεσε ολόκληρη την conflicting ομάδα:

```python
keys = out["text"].map(canonical_text)
label_counts = out.groupby(keys)["label"].transform("nunique")
out = out.loc[label_counts.eq(1)].copy()
out["_key"] = out["text"].map(canonical_text)
out = out.drop_duplicates("_key").drop(columns="_key").reset_index(drop=True)
out["review_id"] = out["text"].map(review_id)
```

- [ ] Πρόσθεσε public test για null/empty source fields. Χρησιμοποίησε `fillna("")` και ρητή μη κενή written πλευρά, ώστε το string `nan` να μη γίνεται review.
