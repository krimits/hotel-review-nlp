# Ανάλυση κριτικών ξενοδοχείου · πιλοτική λειτουργία

Για ξενοδοχεία που έχουν λάβει κωδικό συμμετοχής. Επικολλάτε τις πρόσφατες κριτικές των επισκεπτών σας, σε
οποιαδήποτε γλώσσα· για κάθε κριτική βλέπετε ποια προβλήματα αναφέρει, σε ποιο τμήμα πάει το καθένα και ποια είναι
επείγοντα για το δικό σας ξενοδοχείο, και μας λέτε αν η ανάλυση είναι σωστή.

**Η υπηρεσία είναι πειραματική.** Δεν έχει αξιολογηθεί σε πραγματική λειτουργία· αυτό κάνει το πιλοτικό.

**Τα δεδομένα σας.** Τα κείμενα των κριτικών στέλνονται στο OpenRouter και στην Anthropic για την ανάλυση. Εδώ δεν
αποθηκεύεται κανένα κείμενο: κρατάμε μόνο τις κρίσεις σας, σε ιδιωτικό σύνολο δεδομένων, με ψευδώνυμο (P01, P02, …)
και χωρίς το όνομα του ξενοδοχείου.
