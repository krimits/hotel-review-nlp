# Αξιολόγηση αναλύσεων κριτικών (τυφλή)

Για ξενοδόχους που έχουν λάβει κωδικό συμμετοχής. Κάθε κριτική εμφανίζεται με δύο αναλύσεις, «Σύστημα 1» και
«Σύστημα 2»· κρίνετε αν τα επείγοντα είναι σωστά, αν τα υπόλοιπα είναι σωστά, πόσο χρήσιμη είναι η κάθε ανάλυση, και
ποια θα προτιμούσατε. Οι κριτικές είναι δημόσιες, αγγλικές, για άλλα ξενοδοχεία (Booking.com, 2015–2017).

Οι απαντήσεις αποθηκεύονται σε ιδιωτικό σύνολο δεδομένων με τον ψευδώνυμο κωδικό σας (H01, H02, …), χωρίς ονόματα.
Η αξιολόγηση ακολουθεί πρωτόκολλο που κλειδώθηκε πριν από κάθε απάντηση.
